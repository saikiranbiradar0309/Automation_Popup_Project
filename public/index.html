Everything You Need to Practice

Real elements, real challenges. Built to reflect actual production websites your automation scripts will face.

💬

Popups & Modals

Browser alert, confirm, prompt dialogs plus custom JS modals. Timed popups, nested popups and unexpected popups to test your wait strategies.

📅

Calendar Handling

Navigate month/year pickers, select date ranges, test disabled dates and verify min/max constraints — the exact scenarios you encounter in e-commerce and booking sites.

☑️

Checkboxes

Individual, group, and indeterminate state checkboxes. Select-all functionality with dynamic state tracking to test your check/uncheck logic.

📝

Inputs & Radio Buttons

Text, number, email, URL, password, date, color, range, and textarea inputs. Radio button groups with form submission and validation.

🔽

Dropdowns

Standard HTML select, multi-select, and custom JavaScript-driven dropdown menus. Searchable dropdowns to test your Select2 and custom element strategies.

🪟

Frames & iFrames

Single frames, nested frames and dynamically loaded iframes. Switch between frames and interact with content inside — a classic automation challenge.

📤

File Upload

Standard input upload, drag-and-drop zone, multiple file upload and file type/size validation. Practice sendKeys and interacting with file dialogs.

🔐

Authentication

Login, logout, and signup flows with session management. Test credential validation, error messages, and protected route redirects.

🔌

REST API Endpoints

Node.js Express backend with real API responses. Test HTTP interactions, form submissions and file upload APIs — great for API testing practice too.
